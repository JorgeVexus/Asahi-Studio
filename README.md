## 🚀 Deploy en Vercel

### Opción 1: Deploy Manual (Drag & Drop)
1. Comprime todos los archivos en un ZIP
2. Ve a [vercel.com](https://vercel.com)
3. Arrastra el ZIP a la consola
4. Listo

### Opción 2: Deploy con Git (Recomendado)
```bash
# Inicializa git
git init
git add .
git commit -m "Initial commit"

# Conecta con GitHub
git remote add origin https://github.com/tuusuario/asahi-studio.git
git push -u origin main

# Conecta repo en Vercel
# Ve a vercel.com → New Project → Import from GitHub
```

### Opción 3: CLI de Vercel
```bash
# Instala Vercel CLI
npm i -g vercel

# Deploy
vercel

# Deploy a producción
vercel --prod
```
