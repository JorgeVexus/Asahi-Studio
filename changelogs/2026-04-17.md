# Changelog - 2026-04-17

## Project: Asahi Studio - Client Ticketing & Support System

### 🚀 Overview
Implemented a professional Ticketing and Change Control system to centralize client requests and eliminate informal communication via WhatsApp.

### ✨ Key Features
- **Client Ticketing Portal**: Created a standalone portal at `/portal` for clients to submit bugs, adjustments, and feedback.
- **Admin Management Dashboard**: Built a management view at `/dashboard/tickets.html` to track, prioritize, and respond to tickets.
- **Supabase Storage Integration**: Enabled file and screenshot uploads for both clients and admins to provide visual context for adjustments.
- **Real-time Communication**: Integrated Supabase Realtime for instant chat-like message updates without page refreshes.

### 🛠️ Technical Implementation
- **Database Schema**: 
    - Created `asahi_tickets` for tracking project support requests.
    - Created `asahi_ticket_messages` for threaded conversations with `jsonb` attachment support.
- **Storage Management**: Configured logic to handle uploads to the `tickets` bucket with unique path generation (`client/` and `admin/`).
- **UI/UX**:
    - **Dynamic Rendering**: Automatic detection of image vs document attachments for inline previews.
    - **Dashboard Sync**: Added a global "Ajustes Pendientes" counter to the main dashboard navigation.
- **Security**: Configured RLS policies for ticket isolation and secure admin access.
